# هوية منصة رِفاد البصرية

| الملف | الاستخدام |
|---|---|
| `logo.svg` | الشعار الأفقي الكامل (الرمز + الاسم) — للترويسات والتقارير |
| `logo-light.svg` | النسخة البيضاء — للخلفيات الداكنة فقط |
| `logo-mark.svg` | الرمز وحده — للشريط الجانبي والأيقونات |
| `../logo.svg` | الرمز على شبكة شفافة (96×96) — للاستخدام العام |
| `../favicon.svg` | الرمز على خلفية مستديرة — أيقونة المتصفح |
| `../../src/app/icon.svg` | أيقونة الموقع التي يقرأها Next.js تلقائياً |
| `../icons/icon-*.png` | أيقونات تطبيق الويب (PWA) بمقاسي 192 و512 |

## الألوان

| اللون | القيمة | الاستخدام |

| أزرق ليلي | `#0B2545` | الأساس، النصوص، الترويسات |

| زمردي | `#0E7C66` | النجاح، النمو، الروابط |
| فيروزي | `#17A89A` | التمييز، التفاعل، التقدم |
| ذهبي | `#C9A227` | الاعتماد، الثقة، الرموز الرسمية |
| عاجي | `#F7F5F0` | خلفية الصفحات |

الخط: **أميري** للعناوين والنصوص العربية (خط نسخي كلاسيكي)، وخط النظام للنصوص الصغيرة.

## بنية الرمز

درع سداسي بحدٍّ ذهبي، يحتضن:
- **نجمة ذهبية** في الأعلى: الاعتماد والتميّز.
- **كتاب مفتوح** في الوسط: المدرسة والمعرفة.
- **قوس فيروزي** في الأسفل: النمو والتقدّم المستمر.

## الاستخدام

- مساحة حماية حول الشعار لا تقل عن ارتفاع النجمة.
- لا تُغيّر ألوان الشعار أو تُدوّر الرمز.
- على خلفية داكنة يُستخدم الرمز وحده أو نسخة بيضاء من الاسم.
