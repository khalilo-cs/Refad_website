## نطاق البيانات

- **مدير النظام:** كل المدارس.
- **مدير الإدارة:** مدارس مديريته فقط.
- **المفتش:** المدارس المسندة إليه وزياراته، أو مدارس مديريته إن لم تُسند إليه مدارس.
- **مدير المدرسة ومنسق الجودة:** مدرستهما فقط.
- **المعلم:** ما رفعه بنفسه من أدلة.

## صلاحيات دورة التحسين

| العملية | من يستطيع |
|---|---|
| تقييم المؤشرات في الاختبار والاستمارة، ووضع إشارة الضعف | مدير المدرسة، ومنسق الجودة (لمدرستهما، قبل الإرسال) |
| وضع خطة التحسين، وبدء التنفيذ، وإعلان التحسّن | مدير المدرسة، ومنسق الجودة |
| إرسال الاستمارة | مدير المدرسة، ومنسق الجودة (بعد اكتمال الشروط) |
| اعتماد التحسّن، أو إعادته، أو سحب اعتماده | مدير النظام، ومدير الإدارة، والمفتش (ضمن نطاقهم) |
| إعادة فتح استمارة مُرسلة | مدير النظام، ومدير الإدارة، والمفتش |
| تذكير المدارس، والاطلاع على نقاط الضعف الشائعة | مدير النظام، ومدير الإدارة، والمفتش |
| إصدار شهادة تقدير | مدير النظام، ومدير الإدارة |
| إلغاء شهادة | مدير النظام فقط |
| إضافة جهات اتصال المدرسة | مدير النظام، ومدير الإدارة، ومدير المدرسة |

## قواعد حماية ثابتة

- لا يمكن تعطيل **آخر مدير نظام نشط** ولا تغيير دوره.
- لا يستطيع المستخدم قفل حسابه أو تعطيله بنفسه.
- تغيير الدور أو كلمة المرور، أو القفل أو التعطيل، يُنهي **جلسات المستخدم المفتوحة فوراً**.
- الحساب الذي يلزمه تغيير كلمة المرور لا يصل إلى أي بيانات قبل تغييرها، حتى لو استدعى الواجهات البرمجية مباشرة.
- الاختبار التفاعلي إجباري **في الخادم أيضاً**: لا يُقبل أي تقدير لم يمرّ بسؤال الأدلة.
