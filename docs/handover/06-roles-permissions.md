# الفصل السادس: الأدوار والصلاحيات

في المنصة **ستة أدوار** جاهزة. ينشئ الحسابات ويحدد أدوارها **مدير النظام وحده**.

| الدور | من يحمله |
|---|---|
| **مدير النظام** | رئيس قسم الجودة والاعتماد المدرسي: **أ. ابتسام التبيلي** (ماجستير إدارة وإشراف تربوي)، ومن تكلّفه من فريقها |
| **مشرف المحافظة** | قيادات المحافظة للاطلاع والمتابعة: **أ. عمر بحر** (مدير مكتب التربية والتعليم والبحث العلمي بالمحافظة)، و**أ. فهمي المقطري** (مدير إدارة الجودة والاعتماد المدرسي بالمحافظة) |
| **المفتش / الموجّه التربوي** | من يختارهم مدير النظام، ولكل منهم مدارس مسندة |
| **مدير المدرسة** | مدير كل مدرسة |
| **منسق الجودة بالمدرسة** | مسؤول الجودة داخل كل مدرسة |
| **المعلم** | معلمو المدارس |

## نطاق البيانات

- **مدير النظام:** كل المدارس، ويعدّل كل شيء.
- **مشرف المحافظة:** كل المدارس **اطلاعاً فقط**. يرفض الخادم أي طلب تعديل من حسابه، ما عدا تغيير كلمة مروره وإعدادات حسابه وقراءة إشعاراته.
- **المفتش:** **المدارس التي أسندها إليه مدير النظام** ومدارس زياراته فقط. لا يرى مدرسة لم تُسند إليه.
- **مدير المدرسة ومنسق الجودة بالمدرسة:** مدرستهما وبياناتهما فقط. لا يصل أحدهما إلى مدرسة أخرى أو حساب مدير آخر، ولا يعدّل بيانات أي شخص غيره.
- **المعلم:** ما رفعه بنفسه من أدلة.

## صلاحيات دورة التحسين

| العملية | من يستطيع |
|---|---|
| تقييم المؤشرات في الاختبار والاستمارة، ووضع إشارة الضعف | مدير المدرسة، ومنسق الجودة بالمدرسة (لمدرستهما، قبل الإرسال) |
| وضع خطة التحسين، وبدء التنفيذ، وإعلان التحسّن | مدير المدرسة، ومنسق الجودة بالمدرسة |
| إرسال الاستمارة | مدير المدرسة، ومنسق الجودة بالمدرسة (بعد اكتمال الشروط) |
| اعتماد التحسّن، أو إعادته، أو سحب اعتماده | مدير النظام، والمفتش (ضمن نطاقه) |
| إعادة فتح استمارة مُرسلة | مدير النظام، والمفتش (ضمن نطاقه) |
| تذكير المدارس | مدير النظام، والمفتش |
| الاطلاع على نقاط الضعف الشائعة | مدير النظام، ومشرف المحافظة، والمفتش |
| إصدار شهادة تقدير، أو إلغاؤها | مدير النظام فقط |
| اعتماد الزيارة الميدانية أو إعادتها، واعتماد التقارير أو رفضها | مدير النظام فقط |
| مراجعة الشواهد (قبول أو رفض) | مدير النظام، والمفتش، ومنسق الجودة بالمدرسة |
| حذف الشواهد | مدير النظام فقط |

## صلاحيات البيانات الأساسية

| العملية | من يستطيع |
|---|---|
| إنشاء الحسابات وتعديلها وحذفها وتحديد أدوارها | مدير النظام فقط |
| اختيار المفتشين وإسناد المدارس لكل مفتش | مدير النظام فقط |
| إضافة المدارس واستيرادها، وتعديل السجل الرئيسي للمدرسة (الاسم والرمز والمديرية والموقع وبيانات الاتصال الرسمية) | مدير النظام فقط |
| تحديث ملف المدرسة (أعداد الطلاب والمعلمين والفصول والمرافق) | مدير النظام، والمفتش، ومدير مدرسته |
| توثيق ملف المدرسة | مدير النظام، والمفتش |
| إضافة جهات اتصال المدرسة | مدير النظام، ومدير المدرسة |
| نشر الإعلانات | مدير النظام (لكل المدارس)، ومدير المدرسة (لمدرسته) |
| تعديل محتوى الاستمارة والمقياس والأدوار والإعدادات | مدير النظام فقط |

## قواعد حماية ثابتة

- لا يمكن تعطيل **آخر مدير نظام نشط** ولا تغيير دوره ولا حذفه.
- لا يستطيع المستخدم قفل حسابه أو تعطيله أو حذفه بنفسه.
- تغيير الدور أو كلمة المرور، أو القفل أو التعطيل أو الحذف، يُنهي **جلسات المستخدم المفتوحة فوراً**. والدور والمدرسة يُقرآن من قاعدة البيانات مع كل طلب، فيسري أي تغيير في الحال.
- **تسجيل الخروج يُنهي جلسات المستخدم على كل أجهزته.**
- الحساب الذي يلزمه تغيير كلمة المرور لا يصل إلى أي بيانات قبل تغييرها، حتى لو استدعى الواجهات البرمجية مباشرة.
- الاختبار التفاعلي إجباري **في الخادم أيضاً**: لا يُقبل أي تقدير لم يمرّ بسؤال الأدلة.
- كل الصلاحيات تُفحص **في الخادم** مع كل طلب؛ إخفاء الأزرار في الواجهة ليس الحماية الوحيدة.
