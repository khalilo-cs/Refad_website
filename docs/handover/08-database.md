# الفصل الثامن: قاعدة البيانات

قاعدة البيانات علائقية (SQLite أو libSQL/Turso) بالمخطط نفسه. المخطط الأساسي في `prisma/schema.sql`، والإضافات اللاحقة في ترحيلات `src/lib/db/migrations.ts`.

## الجداول حسب الوظيفة

### الهيكل الإداري والمدارس

| الجدول | المحتوى |
|---|---|
| `governorates`، `directorates`، `areas` | المحافظات، والمديريات، والمناطق |
| `schools` | المدارس: الرمز، والاسم، والنوع، والمرحلة، والمدير، والهاتف (ومعه علامة الواتساب)، والإحداثيات ومصدرها، والحالة |
| `school_profiles` | ملف المدرسة: الأعداد والمرافق، مع التحقق منها |
| `school_contacts` | جهات اتصال إضافية: الوكيل، ومنسق الجودة، وغيرهما |
| `school_assignments` | إسناد المدارس إلى المفتشين |

### المستخدمون والأمان

| الجدول | المحتوى |
|---|---|
| `roles` | الأدوار وصلاحياتها (JSON) |
| `users` | الحساب: البريد، واسم المستخدم، والهاتف، والمسمى الوظيفي. والأمان: تجزئة كلمة المرور، والدور، والمدرسة أو المديرية، وحالة القفل والتفعيل، وإصدار الرمز، والمصادقة الثنائية، والإلزام بتغيير كلمة المرور |
| `login_attempts` | محاولات الدخول، الناجحة والفاشلة |
| `security_incidents` | الحوادث الأمنية المسجّلة |
| `audit_logs` | سجل التدقيق لكل إجراء حساس |

### الاستمارة والتقييم

| الجدول | المحتوى |
|---|---|
| `criteria`، `sub_criteria`، `indicators` | المعايير، والمعايير الفرعية، والمؤشرات، مع الأوزان والأدلة وأدوات التحقق |
| `rating_scale` | مقياس التقدير (0–3) |
| `visits` | الزيارات الميدانية وحالاتها |
| `evaluations`، `evaluation_history` | التقييم الميداني لكل مؤشر في الزيارة، وسجل تعديله |

### التقييم الذاتي ودورة التحسين والتكريم

| الجدول | المحتوى |
|---|---|
| `self_assessments` | استمارة المدرسة لعام دراسي: مسودة أو مُرسلة |
| `self_assessment_items` | تقدير كل مؤشر وضعفه وخطته وحالة معالجته، وإجابات الاختبار التفاعلي |
| `self_assessment_history` | تاريخ كل مؤشر، وهو سجل غير قابل للتعديل |
| `certificates` | شهادات التقدير الصادرة: الرمز، والنص، والتفاصيل، ومن أصدرها، وحالة الإلغاء |

### الأدلة والتقارير والتحسين

| الجدول | المحتوى |
|---|---|
| `evidence`، `evidence_versions` | الشواهد المرفوعة وإصداراتها، وحالة مراجعتها، وربطها بالمؤشر أو الزيارة |
| `evidence_library_items` | مكتبة الأدلة المرجعية |
| `reports` | التقارير وحالاتها، ورمز التحقق، ولقطة المحتوى |
| `improvement_plans`، `corrective_actions` | خطط التحسين والإجراءات التصحيحية الناتجة عن التقييم الميداني |
| `export_logs` | سجل عمليات التصدير |

### التواصل والإشعارات

| الجدول | المحتوى |
|---|---|
| `conversations`، `conversation_participants`، `messages` | المراسلات |
| `announcements`، `announcement_reads` | الإعلانات والتعاميم وقراءتها |
| `meetings`، `shared_materials` | الاجتماعات والمواد المشتركة |
| `notifications` | الإشعارات الداخلية |

### أخرى

| الجدول | المحتوى |
|---|---|
| `settings` | إعدادات النظام: الاسم، والحد الأقصى لحجم الملفات، وتاريخ آخر تنبيه يومي، وغيرها |
| `parents`، `students`، `parent_student`، `attendance_records`، `academic_results` | بيانات أولياء الأمور والطلاب (تظهر لولي الأمر) |
| `schema_migrations` | الترحيلات المطبّقة |
