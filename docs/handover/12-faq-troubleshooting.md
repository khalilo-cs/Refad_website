# الفصل الثاني عشر: الأسئلة الشائعة وحل المشكلات

## أسئلة المستخدمين

**نسيت كلمة المرور، ماذا أفعل؟**
اطلب من مدير النظام **إعادة تعيين كلمة المرور**. تصلك كلمة مؤقتة جديدة، وتغيّرها عند الدخول.

**دخلت فظهرت لي صفحة «اختر كلمة مرور جديدة» ولا أستطيع تجاوزها.**
هذا مقصود: حسابك جديد أو أُعيد تعيينه. اكتب الكلمة المؤقتة، ثم كلمة جديدة تحقق الشروط الخضراء، ثم اضغط «حفظ والمتابعة».

**أنا مدير مدرسة، ولا تفتح لي إلا صفحة الاختبار التفاعلي.**
الاختبار **إجباري** حتى تجيب عن كل المؤشرات، ويُحفظ تقدّمك تلقائياً. بعد إكماله تُفتح المنصة كاملة.

**لا أستطيع إرسال الاستمارة.**
يظهر السبب بجانب زر الإرسال: إما مؤشرات لم تُقيَّم، أو نقاط ضعف بلا خطة. افتح بطاقة «بانتظار خطة» لتصل إليها مباشرة.

**أرسلت الاستمارة وأريد تعديل تقدير.**
بعد الإرسال يُقفل التقييم حفاظاً على صدق التاريخ. اطلب من الإدارة «إعادة فتح الاستمارة»، أو حدّث المؤشر عبر مسار التحسين.

**لماذا لا يظهر زر واتساب بجانب رقم؟**
لأحد سببين: الرقم غير صالح (يظهر عليه «رقم غير صالح»)، أو عُلّم بأنه بلا واتساب.

**لماذا لا تستحق مدرسة الشهادة؟**
تظهر رسالة السبب. الشروط: أن تكون الاستمارة مُرسلة، وأن يوجد معيار محقَّق بالكامل أو تحسّن اعتمدته الإدارة.

## مشكلات تقنية

| العَرَض | السبب المحتمل | الحل |
|---|---|---|
| «قاعدة البيانات غير مهيّأة على هذه الاستضافة» | Turso غير مربوطة | Vercel ← Storage ← اربط Turso ← Redeploy |
| «إعداد ناقص: أضف المتغير JWT_SECRET» | السرّ غير مضبوط | أضف `JWT_SECRET` ثم Redeploy |
| «تخزين الملفات غير مهيّأ» عند رفع دليل | Blob غير مربوط | Vercel ← Storage ← اربط Blob ← Redeploy |
| التعديلات الجديدة لا تظهر على الموقع | النشر لم يكتمل أو نُشر كمعاينة (Preview) | Deployments ← آخر نشر ← Promote to Production، واضبط فرع الإنتاج `khalilo-cs` |
| صفحة الدخول تقول بيانات خاطئة رغم صحتها | الحساب مقفل مؤقتاً أو معطّل | انتظر 15 دقيقة، أو افتحه من **المستخدمون** |
| الخريطة رمادية بلا خلفية | الإنترنت ضعيف أو بلاطات OpenStreetMap محجوبة | النقاط تبقى ظاهرة، وتعود الخلفية عند تحسّن الاتصال |
| «تعذّر الوصول إلى الرابط» عند لصق رابط خرائط | الرابط ليس من جوجل أو الشبكة ضعيفة | الصق الإحداثيات مباشرة: اضغط مطولاً على موقع المدرسة في خرائط جوجل وانسخها |
| خطأ عند استيراد الكشف | أعمدة ناقصة أو مديرية غير مطابقة | راجع «تقرير الأخطاء» في المعاينة. أسماء المحافظات والمديريات يجب أن تطابق المسجّلة |

## فحص سريع للنظام

افتح `/api/health`:

```json
{"status":"ok","service":"rifad-platform","database":"connected","engine":"libsql","storage":"blob"}
```

- **`engine`:** نوع قاعدة البيانات: `libsql` على Vercel/Turso، و`sqlite` على الخادم.
- **`storage`:** نوع التخزين: `blob` على Vercel، و`local` على الخادم.
