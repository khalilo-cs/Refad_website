# بطاقة مرجعية سريعة: مدير المدرسة ومنسق الجودة {.card}

| # | ماذا أريد؟ | كيف؟ |
|:-:|-----------------------------|----------------------------------------------------------------------|
| 1 | **أبدأ** | أدخل ← أغيّر كلمة المرور المؤقتة ← أُوجَّه إلى **الاختبار التفاعلي** (إجباري) |
| 2 | **أجيب عن مؤشر** | أحدد الأدلة المتوفرة **فعلاً** ← أداة التحقق ← أراجع التقدير المقترح ← 📎 شاهد (اختياري) ← «حفظ والتالي» |
| 3 | **ظهرت نقطة ضعف** | أكتب الخطة فوراً: **الإجراء** (محدد) + **المسؤول** + **الموعد** |
| 4 | **أتابع الاستمارة** | التقييم الذاتي ← أضغط البطاقات: نقاط الضعف، بانتظار خطة، تجاوز موعد الخطة… |
| 5 | **أضع إشارة ضعف يدوية** | زر «ضعف» على المؤشر ← ثم أضع له خطة |
| 6 | **أبدأ التنفيذ** | «بدأنا التنفيذ» على المؤشر ← يصير 🔵 |
| 7 | **أعلن التحسّن** | أرفع الشاهد أولاً ← «تمّت المعالجة وتحسّن» ← ما نُفّذ + تقدير أعلى ← «إرسال للاعتماد» ← يصير 🟢 فاتح |
| 8 | **أرسل الاستمارة** | كل المؤشرات مقيّمة + لكل ضعف خطة ← «إرسال للإدارة». للتعديل بعدها أطلب «إعادة فتح» |
| 9 | **أطبع الاستمارة** | «طباعة الاستمارة» ← طابعة أو «حفظ بتنسيق PDF» |
| 10 | **أراجع شواهد المعلمين** (المنسق) | الأدلة والشواهد ← «مراجعة» ← فتح الملف ← الصلاحية ← ملاحظة (إلزامية عند الرفض) ← «قبول» أو «رفض» |
| 11 | **أنشر إعلاناً** (المدير) | التواصل ← الإعلانات ← «إعلان جديد» ← الجمهور ← «نشر» |
| 12 | **أحدّث جهات الاتصال** (المدير) | المدارس ← مدرستي ← جهات الاتصال والموقع |

**ألوان المؤشر:** 🔴 ضعيف يحتاج خطة · 🟠 خطة موضوعة · 🔵 قيد التنفيذ · 🟢 فاتح بانتظار الاعتماد · 🟢 تحسّن معتمد

> **تذكّر:** تقدّمك في الاختبار محفوظ دائماً. الصدق في التقييم يصنع تحسّناً معتمداً يُكرَّم عليه.
