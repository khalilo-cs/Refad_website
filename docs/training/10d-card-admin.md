# بطاقة مرجعية سريعة: رئاسة المنصة ومدير النظام {.card}

| # | ماذا أريد؟ | كيف؟ |
|:-:|------------------------|----------------------------------------------------------------------|
| 1 | **أرى نواقص البيانات** | الإدارة ← مركز التحكم ← أضغط البطاقة ← أعالج من القائمة |
| 2 | **أضيف مدرسة** | المدارس ← إضافة مدرسة ← البيانات + الهاتف + الموقع (خريطة، أو GPS، أو رابط جوجل) |
| 3 | **أستورد مدارس** | المدارس ← استيراد ← أرفع الكشف ← «تحديث المدارس الموجودة» ← المعاينة ← «تأكيد» |
| 4 | **أنشئ حساباً** | المستخدمون ← «مستخدم جديد» ← الدور (مفتش، أو مشرف محافظة، أو أدوار المدرسة) ← كلمة المرور فارغة (تُولَّد) ← أسلّمها: نسخ، واتساب، طباعة، تنزيل ملف |
| 5 | **أسند مدارس لمفتش** | المستخدمون ← 🏫 «المدارس المسندة» بجانب المفتش ← أحدد المدارس ← «حفظ الإسناد» |
| 6 | **أنشئ حسابات المدراء دفعة** | «حسابات مدراء المدارس» ← حتى 20 مدرسة ← «إنشاء الحسابات» ← **PDF أو Excel أو CSV** |
| 7 | **نسي مستخدم كلمته** | 🔑 «إعادة تعيين كلمة المرور» ← أسلّمه الكلمة المؤقتة |
| 8 | **أوقف حساباً مؤقتاً** | ⏻ «تعطيل» (يمكن التراجع) أو 🔒 «قفل» |
| 9 | **أحذف حساباً نهائياً** | 🗑 «حذف الحساب» ← «تأكيد». يختفي، ويتحرر اسم دخوله، وتبقى أعماله |
| 10 | **أصدّر المستخدمين** | المستخدمون ← «تصدير Excel» أو «تصدير CSV» (بلا كلمات مرور) |
| 11 | **أعدّل الاستمارة** | الإدارة ← المعايير والمؤشرات (مجموع الأوزان 100%) |
| 12 | **أتتبع إجراءً** | الإدارة ← سجل التدقيق ← بحث بالإجراء أو المستخدم أو التاريخ |
| 13 | **أحفظ نسخة احتياطية** | الإدارة ← «نسخة احتياطية» (أسبوعياً، وتُحفظ في مكان آمن) |

**قواعد ثابتة:** لا تحذف ولا تعطّل حسابك، ولا آخر مدير نظام نشط. تغيير الدور أو كلمة المرور أو القفل أو التعطيل أو الحذف يُنهي جلسات المستخدم فوراً.

> **تذكّر:** فعّل المصادقة الثنائية على حسابك، وأتلف ملفات كلمات المرور بعد التسليم.
