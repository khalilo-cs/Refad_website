### تفسير النتائج

| النسبة في الاختبار البعدي | التقدير | الإجراء المقترح |
|-------------------------|-----------|-----------------------------------|
| 90% فأكثر | ممتاز | يمكن أن يساعد زملاءه في مدرسته |
| 80% – 89% | جيد جداً | مستعد للعمل على المنصة |
| 60% – 79% | مقبول | يراجع الكتيّب، ويحضر جلسة المتابعة |
| أقل من 60% | يحتاج دعماً | جلسة دعم فردية قبل بدء العمل الفعلي |

## 2. معايير تصحيح التمارين العملية

| التمرين | ما يتحقق منه المدرّب على المنصة |
|---------------------|----------------------------------------------------------------------|
| **1-1** أول دخول | لم يعد الحساب في قائمة «بانتظار تغيير كلمة المرور» |
| **1-3** حماية الحساب | رقم الهاتف محفوظ في الحساب |
| **2-1** رفع ملف | الملف ظاهر في الأدلة والشواهد بحالة «بانتظار المراجعة»، مع نوع المستند الصحيح |
| **2-3** النسخة الجديدة | شارة «نسخة 2» على الملف نفسه، وليس ملفاً منفصلاً |
| **3-2** خطة جيدة | الإجراء محدد يمكن رؤيته، والمسؤول وظيفة محددة، والموعد واقعي |
| **3-4** قراءة الاستمارة | بطاقة «بانتظار خطة» = 0 |
| **3-5** الاعتماد | التاريخ يُظهر: خطة ← تنفيذ ← تحسّن ← قرار الإدارة |
| **3-6** الإرسال | حالة الاستمارة «مُرسلة» في لوحة المتابعة |
| **4-3** الاعتماد والإعادة | سبب الإعادة واضح ويحدد المطلوب |
| **4-4** دراسة الحالة | الاقتراح مبني على أرقام «نقاط الضعف الشائعة»، لا على الانطباع |
| **5-3** دورة حياة حساب | إجراء `USER_DELETED` ظاهر في سجل التدقيق باسم المتدرب |
| **5-6** التنظيف | لا حسابات تدريب نشطة، ومدارس التدريب مؤرشفة |
