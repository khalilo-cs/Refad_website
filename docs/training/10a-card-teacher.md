# بطاقة مرجعية سريعة: المعلم {.card}

| # | ماذا أريد؟ | كيف؟ |
|:-:|--------------------|----------------------------------------------------------------------|
| 1 | **أدخل أول مرة** | اسم الدخول وكلمة المرور من بطاقتي ← أختار كلمة جديدة: 10 أحرف على الأقل، فيها حرف إنجليزي ورقم ← «حفظ والمتابعة» |
| 2 | **أرفع ملف إنجاز** | الأدلة والشواهد ← «رفع دليل» ← أختار الملف ← المؤشر (اختياري) ← نوع المستند ← «رفع» |
| 3 | **أعرف حالة ملفاتي** | لوحة التحكم: المرفوعة، والمقبولة، وبانتظار المراجعة. أو بطاقات الحالة في الأدلة والشواهد |
| 4 | **ملفي رُفض** | أقرأ «ملاحظة المراجعة» ← أصحّح الملف ← 🔄 «رفع نسخة جديدة» على الملف نفسه |
| 5 | **أعاين أو أنزّل ملفاً** | 👁 معاينة · ⬇ تنزيل · 📋 رابط مؤقت (5 دقائق) · 🕘 سجل النسخ |
| 6 | **أراسل إدارة المدرسة** | التواصل ← المراسلات ← «رسالة جديدة» ← المستلمون ← العنوان والرسالة ← «إرسال» |
| 7 | **أقرأ التعاميم** | لوحة التحكم، أو التواصل ← الإعلانات والتعميمات |
| 8 | **أشارك مادة تعليمية** | التواصل ← المواد التعليمية ← «مادة جديدة» ← مجتمع المدرسة أو أولياء الأمور ← «نشر» |
| 9 | **أحمي حسابي** | الإعدادات ← الأمان: تغيير كلمة المرور، والمصادقة الثنائية، وإنهاء الجلسات الأخرى |
| 10 | **نسيت كلمة المرور** | أطلب من إدارة المنصة إعادة تعيينها |

**الملفات:** كل الأنواع الشائعة مقبولة: صور، فيديو، صوت، PDF، Word، Excel، PowerPoint، ZIP. **ممنوع:** البرامج والملفات البرمجية. **الحجم:** نحو 4 ميجابايت للملف.

> **تذكّر:** لا يرى ملفاتك إلا إدارة مدرستك ومديرة قسم الجودة والمفتش ومدير النظام.
