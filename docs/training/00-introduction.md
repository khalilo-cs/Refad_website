# مقدمة الحقيبة التدريبية

## عن هذه الحقيبة

هذه **الحقيبة التدريبية الشاملة لمنصة رفاد للاعتماد المدرسي وضمان جودة التعليم**. أُعدّت لتنفيذ دورة تدريبية كاملة يقدّمها **فريق رئاسة المنصة** لكل مستخدميها: المعلمين، ومدراء المدارس ومنسقي الجودة، والمشرفين في الإدارة التعليمية، ومدراء النظام.

تشرح الحقيبة **كل جزء في المنصة خطوة بخطوة**، بصور حقيقية من شاشاتها، وتضيف إلى الشرح ما يحتاجه التدريب: خطة الجلسات، والتمارين العملية، والاختبارات، والبطاقات المرجعية، واستمارات التقييم.

> **جميع صور الشاشات في هذه الحقيبة مأخوذة من بيانات تجريبية وهمية**، مثل «مدرسة رفاد التجريبية» و«معلم تجريبي». لا تمثّل مدارس أو أشخاصاً حقيقيين.

## الكتيّبات الجاهزة للطباعة

تُخرَج الحقيبة في عدة ملفات، ليطبع المدرّب لكل فئة ما يخصها فقط:

| الملف | محتواه |
|-------------------------------------|----------------------------------------------------------------------|
| **الحقيبة التدريبية الكاملة** (PDF وWord) | كل ما سبق |
| **دليل المدرّب** | دليل المدرّب، وخطة الجلسات، والتقويم، ومفتاح الإجابات |
| **دليل المعلم** | الأساسيات، ووحدة المعلم، ووحدة الملفات، والبطاقة المرجعية، والأسئلة الشائعة |
| **دليل مدير المدرسة ومنسق الجودة** | الأساسيات، ووحدة المدرسة، ووحدة الملفات، والبطاقة المرجعية، والأسئلة الشائعة |
| **دليل الإدارة والإشراف** | الأساسيات، ووحدة الإشراف، ووحدة الملفات، والبطاقة المرجعية، والأسئلة الشائعة |
| **دليل رئاسة المنصة ومدير النظام** | الأساسيات، ووحدتا الإشراف والإدارة، ووحدة الملفات، والبطاقة المرجعية، والأسئلة الشائعة |
| **العرض التقديمي للدورة** (PowerPoint) | شرائح الجلسات، يعرضها المدرّب على الشاشة |

## الأهداف العامة للدورة

في نهاية الدورة يكون كل متدرب قادراً على أن:

1. **يدخل المنصة بأمان:** يغيّر كلمة المرور المؤقتة، ويحمي حسابه، ويستخدم المنصة من الكمبيوتر والجوال.
2. **يفهم فكرة المنصة:** استمارة التقييم الذاتي، ومقياس التقدير، ودورة نقطة الضعف من اكتشافها حتى اعتماد تحسّنها.
3. **يؤدي مهام دوره كاملة دون مساعدة**، كما تصفها وحدته التدريبية.
4. **يرفع الشواهد والملفات بأي صيغة مسموحة**، ويعرف الحجم المسموح، وينزّل التقارير والبيانات بالصيغة التي يحتاجها.
5. **يتواصل عبر المنصة:** المراسلات، والإعلانات، والاجتماعات، والمواد التعليمية.
6. **يحل المشكلات الشائعة بنفسه**، ويعرف متى يرجع إلى الإدارة.

## مصطلحات أساسية قبل البدء

| المصطلح | المعنى المختصر |
|----------------|----------------------------------------------------------------------|
| **الاستمارة** | استمارة التقييم الذاتي للمدرسة الصادرة عن مجلس الاعتماد الأكاديمي وضمان جودة التعليم |
| **المعيار** | محور رئيسي في الاستمارة. عددها 7، ولكل منها وزن |
| **المؤشر** | عبارة دقيقة تقيس جانباً من المعيار. عددها 109 |
| **الدليل أو الشاهد** | وثيقة أو صورة أو ملف يثبت تحقق المؤشر |
| **نقطة الضعف** | مؤشر تقديره «غير متحقق» أو «متحقق بدرجة ضعيفة»، أو وُضعت عليه إشارة ضعف |
| **خطة التحسين** | الإجراء الذي تعالج به المدرسة نقطة الضعف، ومسؤوله، وموعده |
| **الاعتماد** | تأكيد الإدارة أن التحسّن حدث فعلاً بعد مراجعة الشواهد |

تجد قاموس المصطلحات كاملاً في آخر الحقيبة.
