# بطاقة مرجعية سريعة: الإدارة والإشراف {.card}

| # | ماذا أريد؟ | كيف؟ |
|:-:|---------------------------|----------------------------------------------------------------------|
| 1 | **روتيني اليومي** | متابعة الجودة والتحسين ← بطاقة «تحسّن بانتظار اعتمادك» ← ثم «خطط متأخرة» |
| 2 | **أفتح استمارة مدرسة** | من جدول المتابعة: «فتح» |
| 3 | **أعتمد تحسّناً** | أقرأ ما نُفّذ ← أعرض الشواهد ← «اعتماد التحسّن» + ملاحظة اختيارية |
| 4 | **أعيد تحسّناً** | «إعادة للمتابعة» ← **سبب الإعادة** (إلزامي) ← «إعادة» |
| 5 | **أفتح استمارة مُرسلة للتعديل** | شريط حالة استمارة المدرسة ← «إعادة فتح للمدرسة» |
| 6 | **أذكّر المدارس** | أزرار: من لم يكمل الاختبار · الخطط الناقصة والمتأخرة · الإرسال ← ثم واتساب لكل مدرسة |
| 7 | **أخطط للدعم** | تبويب «نقاط الضعف الشائعة»: أضعف المؤشرات والأدلة الأكثر غياباً |
| 8 | **أصدر شهادة** (مدير الإدارة) | 🏅 بجانب المدرسة ← النص المبني على البيانات ← «إصدار وطباعة» |
| 9 | **أتحقق من شهادة أو تقرير** | صفحة `/verify` ← رمز التحقق |
| 10 | **أراجع شاهداً** | الأدلة والشواهد ← «بانتظار المراجعة» ← «مراجعة» ← «قبول» أو «رفض» بملاحظة |
| 11 | **أنفّذ زيارة** | الزيارات الميدانية ← جدولة ← التقييم الميداني (حفظ تلقائي، ويعمل دون إنترنت) |
| 12 | **أنزّل البيانات** | المتابعة: CSV · المدارس: Excel وCSV · التقارير: PDF وExcel وCSV · دليل الاتصال: CSV وVCF |

**شروط الشهادة:** استمارة مُرسلة + (معيار محقَّق بالكامل: كل مؤشراته مقيّمة، ولا ضعف مفتوح، و80% فأكثر) **أو** تحسّن معتمد.

> **تذكّر:** سبب الإعادة الواضح يوفّر على المدرسة والإدارة جولة كاملة.
