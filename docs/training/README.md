## الملفات الجاهزة

في مجلد `output/`:

| الملف | المحتوى |
|---|---|
| `الحقيبة-التدريبية-الكاملة.pdf` | الحقيبة كاملة للطباعة |
| `الحقيبة-التدريبية-الكاملة.docx` | النسخة نفسها بصيغة Word قابلة للتعديل |
| `العرض-التقديمي-للدورة.pptx` | شرائح الجلسات، مع ملاحظات المدرّب أسفل كل شريحة |
| `دليل-المدرب.pdf` | دليل المدرّب، وخطة الجلسات، والتقويم، ومفتاح الإجابات |
| `دليل-المعلم.pdf` | كتيّب المعلمين |
| `دليل-مدير-المدرسة-ومنسق-الجودة.pdf` | كتيّب المدارس |
| `دليل-الإشراف-والمتابعة.pdf` | كتيّب المفتشين |
| `دليل-مشرف-المحافظة.pdf` | كتيّب مشرفي المحافظة |
| `دليل-رئاسة-المنصة-ومدير-النظام.pdf` | كتيّب رئاسة المنصة |

## إعادة التوليد بعد التعديل

من جذر المشروع:

```bash
node docs/training/build.mjs      # ملفات PDF وWord
python3 docs/training/slides.py   # العرض التقديمي
```

المتطلبات: pandoc، وPlaywright مع Chromium، وpython-pptx وPillow.

> جميع صور الشاشات من نسخة تدريبية منفصلة ببيانات وهمية، لا من الموقع الفعلي. صور `images/` خاصة بالحقيبة، وبقية الصور مشتركة مع دليل التسليم في `../handover/images/`.
