# الأسئلة الشائعة وحل المشكلات والمصطلحات

## 1. الدخول والحساب

**نسيت كلمة المرور. ماذا أفعل؟**
اطلب من مدير النظام **إعادة تعيين كلمة المرور**. تصلك كلمة مؤقتة جديدة، وتغيّرها عند الدخول.

**تظهر «بيانات تسجيل الدخول غير صحيحة» رغم أنني متأكد منها.**

- تأكد أن لوحة المفاتيح **إنجليزية**، وأن زر الأحرف الكبيرة Caps Lock غير مفعّل.
- اكتب اسم الدخول كما في بطاقتك بالضبط.
- إن أخطأت 5 مرات، انتظر **15 دقيقة**، أو اطلب من الإدارة فتح الحساب.
- ربما عُطّل حسابك أو حُذف. راجع الإدارة.

**تظهر صفحة «اختر كلمة مرور جديدة» ولا أستطيع تجاوزها.**
هذا مقصود: حسابك جديد أو أُعيد تعيينه. اكتب الكلمة المؤقتة، ثم كلمة جديدة تحقق كل الشروط الخضراء.

**غيّرت هاتفي. هل أفقد الدخول بالمصادقة الثنائية؟**
اطلب من مدير النظام المساعدة في إعادة ضبط حسابك، ثم فعّل المصادقة على هاتفك الجديد.

**لا أرى قسماً يراه زميلي.**
الأقسام تظهر حسب **الدور**. المعلم مثلاً لا يرى الاستمارة. إن كان دورك خطأ، راجع مدير النظام.

## 2. الاختبار التفاعلي والاستمارة

**أنا مدير مدرسة ولا تفتح لي إلا صفحة الاختبار التفاعلي.**
الاختبار **إجباري** حتى تجيب عن كل المؤشرات، وتقدّمك محفوظ. بعد إكماله تُفتح المنصة كاملة. التواصل والإعدادات والطباعة متاحة دائماً.

**أجبت عن مؤشر بخطأ. هل أستطيع تعديله؟**
نعم قبل الإرسال: من الاختبار بزر «السابق» أو «مراجعة كل الإجابات»، أو من أزرار التقدير في الاستمارة.

**لا أستطيع إرسال الاستمارة.**
يظهر السبب بجانب الزر: مؤشرات لم تُقيَّم، أو نقاط ضعف بلا خطة. اضغط بطاقة «بانتظار خطة» لتصل إليها.

**أرسلت الاستمارة وأريد تعديل تقدير.**
اطلب من الإدارة **«إعادة فتح للمدرسة»**، أو حسّن المؤشر عبر مسار التحسين واعتماده.

**أُعيد تحسّن أعلنته. ماذا أفعل؟**
اقرأ **سبب الإعادة** في الإشعار أو تاريخ المؤشر. أكمل المطلوب وارفع الشاهد الناقص، ثم أعلن التحسّن من جديد.

## 3. الملفات

**رُفض ملفي برسالة «نوع الملف غير مسموح».**
الملف تنفيذي أو برمجي، أو محتواه لا يطابق امتداده. احفظه بصيغة شائعة مثل PDF أو JPG، ثم ارفعه.

**ظهرت رسالة «حجم الملف أكبر مما تسمح به الاستضافة».**
الحد نحو 4 ميجابايت. صغّر الملف بإحدى طرق الوحدة السادسة: صورة بدقة أقل، أو PDF مضغوط، أو فيديو أقصر.

**انقطع الإنترنت أثناء الرفع.**
تظهر رسالة «انقطع الاتصال أثناء الرفع». أعد المحاولة عند تحسّن الاتصال. لا يُحفظ ملف لم يكتمل رفعه.

**الرابط الذي أرسلته لزميلي لا يعمل.**
الرابط المؤقت ينتهي بعد **5 دقائق**. أنشئ رابطاً جديداً، أو اطلب منه فتح الملف من حسابه.

**كيف أحذف ملفاً رفعته بالخطأ؟**
الحذف للإدارة التعليمية فقط حفاظاً على الأرشيف. ارفع **نسخة جديدة** صحيحة على الملف نفسه، أو راسل الإدارة.

## 4. التواصل والإشعارات

**لماذا لا يظهر زر واتساب بجانب رقم؟**
إما أن الرقم غير صالح (يظهر عليه «رقم غير صالح»)، أو عُلّم بأنه بلا واتساب.

**كيف أعرف أن رسالتي قُرئت؟**
تظهر علامة ✓✓ بجانبها. مرّر المؤشر عليها لترى من قرأها.

**الإشعارات كثيرة.**
اضغط **«تعليم الكل كمقروء»** بعد قراءتها. أهمها ما يطلب منك إجراءً: خطة متأخرة، أو تحسّن بانتظار الاعتماد.

## 5. للإدارة ورئاسة المنصة

**لماذا لا تستحق مدرسة الشهادة؟**
تظهر رسالة السبب. الشروط: استمارة مُرسلة، ومعيار محقَّق بالكامل أو تحسّن معتمد.

**حذفت حساباً بالخطأ.**
الحذف لا رجعة فيه، لكن أعمال الحساب محفوظة. أنشئ حساباً جديداً للشخص نفسه، ويمكنك استخدام اسم الدخول نفسه لأنه تحرّر بالحذف.

**أنشأت حسابات المدراء ولم أنزّل كلمات المرور.**
لا يمكن عرضها لاحقاً. أعد تعيين كلمة كل حساب من **المستخدمون**، وسلّم الكلمات الجديدة.

**مدير مدرسة لا يصله التذكير.**
تأكد من مركز التحكم أن للمدرسة **حساب مدير نشطاً**، وأن هاتفها صالح وعليه واتساب.

**التعديلات الجديدة لا تظهر على الموقع.**
انتظر اكتمال النشر، ثم حدّث الصفحة بـ`Ctrl` + `F5`. إن استمرت المشكلة، راجع الفريق الفني.

## 6. قاموس المصطلحات

| المصطلح | المعنى |
|-------------------|----------------------------------------------------------------------|
| **الاعتماد المدرسي** | اعتراف رسمي بأن المدرسة تحقق معايير الجودة المحددة |
| **الاستمارة** | استمارة التقييم الذاتي للمدرسة، الصادرة عن مجلس الاعتماد الأكاديمي وضمان جودة التعليم |
| **المعيار** | محور رئيسي في الاستمارة، مثل «الإدارة المدرسية». عددها 7 |
| **المعيار الفرعي** | قسم داخل المعيار يجمع مؤشرات متقاربة |
| **المؤشر** | عبارة دقيقة قابلة للقياس. عددها 109، ولكل منها رمز مثل `1-1-1` |
| **الدليل أو الشاهد** | ما يثبت تحقق المؤشر: وثيقة، أو صورة، أو سجل، أو محضر |
| **أداة التحقق** | طريقة التأكد: فحص وثائق، أو ملاحظة، أو مقابلة |
| **التقدير** | مستوى تحقق المؤشر: غير متحقق (0)، ضعيف (1)، متوسط (2)، متحقق (3) |
| **نسبة التحقق** | النسبة المئوية لتحقق المعيار أو الاستمارة، محسوبة من التقديرات والأوزان |
| **نقطة الضعف** | مؤشر تقديره 0 أو 1، أو عليه إشارة ضعف يدوية |
| **إشارة الضعف اليدوية** | علامة يضعها المدير على مؤشر يراه يحتاج معالجة رغم تقديره |
| **خطة التحسين** | الإجراء والمسؤول والموعد ومؤشر النجاح لمعالجة نقطة الضعف |
| **إعلان التحسّن** | إبلاغ المدرسة الإدارة بأن الضعف عولج، مع وصف ما نُفّذ وتقدير جديد |
| **اعتماد التحسّن** | تأكيد الإدارة أن التحسّن حدث، بعد مراجعة الشواهد |
| **المعيار المحقَّق** | معيار قُيّمت كل مؤشراته، ولا ضعف مفتوح فيه، ونسبته 80% فأكثر |
| **تاريخ المؤشر** | سجل كل خطوة مرّ بها المؤشر، لا يُحذف ولا يُعدَّل |
| **التقييم الميداني** | تقييم المفتش للمؤشرات أثناء الزيارة، مستقل عن التقييم الذاتي |
| **الإجراء التصحيحي** | خطة تنتج عن التقييم الميداني لكل مؤشر قُيّم 0 أو 1 |
| **رمز التحقق** | رمز فريد على الشهادة أو التقرير، يُتحقق منه في صفحة `/verify` |
| **سجل التدقيق** | سجل لكل إجراء حساس: من فعله ومتى وما تغيّر |
| **المصادقة الثنائية** | حماية إضافية: رمز من تطبيق على الهاتف مع كلمة المرور |
| **كلمة المرور المؤقتة** | كلمة يولّدها النظام عند إنشاء الحساب أو إعادة تعيينه، ويجب تغييرها عند أول دخول |
| **التعطيل** | إيقاف الحساب مع إمكانية إعادة تفعيله |
| **الحذف** | إزالة الحساب نهائياً من القوائم، مع بقاء أعماله السابقة محفوظة |
| **الأرشفة** | إخراج المدرسة من الإحصاءات والمتابعة مع حفظ بياناتها |
| **PDF** | صيغة مستند ثابت الشكل، للطباعة والأرشفة |
| **Excel / CSV** | صيغ جداول بيانات، للفرز والحساب والنقل بين البرامج |
| **VCF** | صيغة ملف جهات اتصال، يُستورد في الهاتف |
